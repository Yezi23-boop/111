学生参与研究主要内容
一、硬件设计与搭建辅助
元器件选型调研：学生在导师指导下，深入研究各类电子元器件资料，对比不同品牌、型号的性能参数。例如针对心率传感器，收集市场上如 MAX30102、PPG101 等多款产品的数据手册，分析其测量精度、功耗、响应时间等关键指标，结合项目预算与功能需求，为团队提供选型建议，形成详细的选型报告。
PCB 设计协助：学习专业 PCB 设计软件，如 Altium Designer 或 KiCad，参与智能手表 PCB 的初步布局布线工作。学生从电路原理理解出发，尝试优化元器件放置位置，缩短关键信号走线长度，减少干扰。在多层 PCB 设计中，协助规划电源层、地层与信号层的分布，参与设计评审，提出改进意见，如增加过孔数量提高接地可靠性等，并跟进 PCB 打样后的电气性能测试，记录测试数据。
二、软件编程与算法实现
底层驱动开发实践：基于 C 或 C++ 语言，学生着手编写部分硬件设备的底层驱动程序片段。以 ESP32 的 GPIO 控制为例，学习如何配置引脚模式，实现对震动马达、LED 灯等执行器的驱动，确保能够精准控制其开关、强度、频率等参数；针对麦克风采集的数据，编写简单的 ADC 转换程序，将模拟信号转换为数字信号供后续处理，理解中断处理机制在数据采集中的应用，提高驱动程序的实时性与稳定性。
声音识别算法优化参与：在导师搭建的深度学习框架基础上，学生协助收集声音样本，从互联网、实地录制等途径获取不同场景下的汽车鸣笛、人声、环境噪音等素材，并进行分类整理与标注。运用 Python 等编程语言，参与构建小型的神经网络模型，尝试调整模型架构，如增加隐藏层神经元数量、改变激活函数等，利用标注数据进行训练，分析模型在不同参数设置下的识别准确率与召回率，将优化结果反馈给导师团队，为整体算法提升提供思路。
三、测试验证与数据分析
功能测试执行：学生制定详细的功能测试用例，涵盖智能手表的所有预设功能。对时间显示功能，测试不同时区设置、夏令时切换下的准确性；针对心率监测，模拟运动、休息等多种状态，检查心率数据的精准度与稳定性；对于声音识别与转化，在安静室内、嘈杂街道等环境下，反复测试对各类声音的识别效果及对应的震动、灯光、文字反馈是否正确，记录测试过程中的问题与现象，及时汇报给项目组。
用户体验数据收集与分析：参与组织盲人、聋人等特殊群体以及普通消费者的用户体验测试活动。在测试现场，学生负责观察用户操作行为，记录他们遇到的困难、提出的建议，如特殊群体用户对手表操作按钮的便捷性反馈、对震动强度舒适度的评价等。通过问卷调查、现场访谈等方式收集数据后，运用统计学方法进行初步分析，制作简单的数据图表，直观展示用户满意度、功能需求优先级等信息，为产品优化提供依据。
四、项目文档整理与汇报
项目汇报展示：经过一段时间的研究实践，学生锻炼自己的汇报能力，制作 PPT 或撰写报告，向项目团队、学校导师以及外部合作单位汇报阶段性成果在汇报中，清晰阐述自己负责的工作内容、取得的进展、遇到的问题及解决方案，接受听众提问，锻炼沟通表达与应变能力,同时也为项目宣传推广积累素材。

预期目标

一、产品成果
成功研发一款基于 ESP32 的智能手表，兼具精准时间显示、实时心率监测、多种环境声音精准识别转化以及人声转文字功能，为盲人、聋人等特殊群体提供全方位的环境感知与沟通辅助，同时满足普通用户对健康管理与便捷生活的需求。
产品外观设计兼顾时尚与实用，贴合人体手腕工程学，确保佩戴舒适、便捷，表带材质多样可选，表盘布局简洁直观，操作按钮易于触及与操控，整体造型符合不同场景穿戴搭配需求。
实现手表与手机等移动终端的无缝连接，通过配套手机应用，用户可轻松查看心率历史数据、声音识别记录，远程调控手表功能设置，如震动强度、灯光颜色、声音识别灵敏度等，拓展产品功能边界，提升用户交互体验。
二、技术成果
攻克复杂环境下声音识别准确率难题，基于深度学习算法构建的声音识别模型，在嘈杂街道、室内多人交谈等典型复杂场景中，对汽车鸣笛、门铃、紧急呼叫等常见声音的识别准确率达到 90%以上，相较于传统识别方法有显著提升，为特殊群体及时感知危险与重要信息提供有力保障。
优化人声转文字技术，结合深度神经网络与语音特征提取算法，在不同口音、语速、语言习惯的人声输入下，文字转换准确率达到 90% 以上，实现实时、流畅的语音文字转换，助力听障用户无障碍交流沟通。
掌握低功耗设计核心技术，通过硬件选型优化与软件智能休眠唤醒策略，使智能手表在开启所有功能的全负荷运行模式下，续航时间达到 10天以上，满足日常使用需求，解决智能穿戴设备续航短板问题。
三、知识产权成果
申请多项与智能手表相关的专利，包括但不限于声音识别算法专利、低功耗硬件设计专利、特殊群体交互设计专利等，构建项目的知识产权壁垒，保护创新成果，提升项目及产品的核心竞争力。
获得软件著作权，涵盖智能手表操作系统、声音识别软件、人声转文字软件、配套手机应用程序等，确保软件层面的自主开发成果得到法律保护，便于后续产品迭代升级与商业化推广。
四、社会成果
切实改善盲人、聋人等特殊群体的生活质量，为他们提供自主出行、社交沟通的有力工具，助力其融入社会主流生活，减少因身体障碍导致的生活不便与心理压力，增强自信心与社会参与感。

项目特色与创新点
一、多模态融合感知交互
全方位环境感知：区别于传统智能手表仅专注于单一功能拓展，本项目创新性地将声音、震动、灯光和文字信息进行深度融合，为用户打造全方位感知外界环境的能力。例如，当身处嘈杂街道，盲人用户不仅能依靠手表的震动强度和节奏变化感知后方车辆的靠近、紧急刹车等情况，还能通过不同颜色闪烁的灯光直观了解周边交通信号灯状态；聋人用户则可凭借精准的人声转文字功能，实时知晓他人交流内容，配合震动提示知晓对话对象的情绪强度，实现无障碍沟通。
自适应交互模式：依据不同用户的感官偏好和使用场景，手表能够自动调整交互模式。在安静的室内学习环境，若检测到轻声呼唤，手表优先以柔和灯光闪烁配合文字显示进行提醒，避免突兀的震动干扰；而在户外跑步锻炼时，面对复杂的交通与环境声音，以强烈且富有节奏的震动为主，辅以灯光警示，确保信息及时传达给用户，最大程度优化用户体验。
二、精准且个性化的声音处理
高精度声音识别：利用基于深度学习的先进算法，对收集到的声音信号进行多维度特征提取与分析。通过构建庞大而精细的声音数据库，涵盖日常生活中的各类场景声音，如不同型号汽车的鸣笛、各类电器警报声、宠物叫声以及丰富的人声语料库，使手表能够精准区分细微差异
三、低功耗与高效能的完美平衡
智能休眠唤醒策略：针对智能手表电池容量有限的瓶颈，设计了一套智能休眠唤醒机制。当环境安静、无明显声音信号且用户长时间未操作时，除保留最基本的时间显示功能外，系统自动进入低功耗休眠状态，关闭不必要的传感器和处理器模块，降低能耗。一旦检测到环境变化或用户抬手等操作，迅速唤醒并在极短时间内恢复全部功能，确保能源的高效利用。
硬件软件协同优化：在硬件选型上，严格筛选低功耗、高性能的元器件，如采用新型低功耗蓝牙芯片、低静态电流的传感器等；软件层面，通过优化算法结构，减少不必要的计算复杂度，采用动态内存分配与管理技术，避免资源浪费。同时，对任务调度进行精细规划，让不同功能模块在执行任务时有序协作，既保障功能的高效实现，又降低整体功耗，使手表在全天 24 小时开启多种功能监测的情况下，仍能维持多天续航。
四、开放生态与拓展潜能
可拓展功能模块：手表预留多个通用接口（如 I2C、SPI 等）和软件 API，方便第三方开发者根据不同用户群体需求、新兴应用场景进行功能拓展。未来有望接入智能家居控制系统，让用户在户外通过手表远程操控家中电器；或者结合医疗健康大数据平台，实现更精准的健康预警与远程医疗协助，不断挖掘产品的潜在价值。
数据共享与社交互动：搭建用户数据共享平台（在用户授权前提下），特殊群体用户可以分享自己的使用心得、生活经验，普通用户也能参与其中，为特殊群体提供帮助与建议。同时，开发社交互动功能，如基于地理位置的特殊群体互助群组，当遇到困难时能够迅速向附近同群体用户求助，形成一个充满关怀与互助的社交生态，进一步提升产品影响力与用户黏性。
