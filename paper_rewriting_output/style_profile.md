# Style Profile

## 目标文体

中文工程竞赛作品报告。风格应正式、清楚、证据导向，面向评委快速理解作品的实用价值、技术路径、完成程度和创新点。

## 语言规则

- 用“本作品”“系统”“手表端”“服务器端”“Hermes”作为稳定主语。
- 每段尽量只承担一个功能：背景、方案、实现、结果或不足。
- 对已实现内容使用确定表达；对规划能力使用“预留”“后续将”“可扩展为”。
- 避免宣传口号式语言，少用“革命性”“颠覆性”“全场景”等夸张词。
- 所有指标必须有证据，没有证据就不写具体数值。

## 推荐句式

- “本作品面向……问题，设计……系统。”
- “手表端负责……，服务器端负责……，Hermes 负责……。”
- “为降低误报，系统采用……策略。”
- “当前已实现……；后续将进一步完善……。”

## 图表优先级

1. 系统总体架构图。
2. 手表端软件模块图。
3. 危险声识别流程图。
4. 风险状态机图。
5. Hermes 联动流程图。
6. 完成情况与测试结果表。

## 匿名与安全规则

- 报告、PPT、视频、截图中不得出现学校名称和指导老师信息。
- 不展示账号、token、服务器密钥、真实定位、私人数据。
- 代码截图只展示关键逻辑，不展示本地绝对路径和敏感配置。
