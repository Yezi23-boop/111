# 计划：创建 feature/espdl-deployment 分支并提交当前更改

## 背景
当前工作区有大量未提交的 ESPDL 双模型推理组件、danger_detection_service 多后端支持、sdkconfig 调整等改动。需要创建一个功能分支来隔离开发。

## 执行步骤

### 1. 确认当前状态
- `git status` 查看当前分支和未提交文件
- `git diff --stat` 查看改动规模

### 2. 创建新分支
- `git checkout -b feature/espdl-deployment` 从当前 HEAD 创建新分支

### 3. 暂存并提交
- `git add -A` 暂存所有更改（新增文件、修改文件、删除文件）
- 提交信息：`功能: 初始化 ESPDL 部署功能开发工作区

- 新增 espdl_inference 组件（V3.2 DS-TCN + V3.3 DS-CNN-tiny 双模型推理）
- danger_detection_service 支持 Edge Impulse / ESPDL 双后端切换
- 关闭 15 个无用 pix_cvt 像素转换选项
- 分支重命名为中文描述性名称`

### 4. 验证分支
- `git branch -v` 显示当前分支名和 HEAD
- `git log -1 --oneline` 显示最新提交

## 风险
- 无，纯 Git 操作，不涉及代码变更
