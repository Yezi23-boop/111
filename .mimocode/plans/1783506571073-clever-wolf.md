# 修复 official_chat activation task 创建失败（栈内存不足）

## 问题分析

**根因**：`StartActivationTask()` 使用 `xTaskCreate()` 分配 8KB 栈，该 API 从 internal SRAM 分配。在音频任务（oa_input/oa_output/oa_opus/worker）已创建后，internal RAM 碎片化导致 8KB 连续块不可用。

**日志证据**：
```
audio task heap (before-create): internal_free=25430 internal_largest=24576
```
音频任务启动后 internal RAM 进一步消耗（oa_opus 栈高水位 23760 字节），到 activation task 创建时已无足够连续空间。

## 修改方案

**文件**: `components/official_chat/application.cc`

### 方案：将 activation task 栈分配到 PSRAM

将 `StartActivationTask()` 中的 `xTaskCreate` 替换为手动从 PSRAM 分配栈 + `xTaskCreateStatic`：

```cpp
void Application::StartActivationTask() {
  if (!started_) {
    return;
  }
  if (activation_task_handle_ != nullptr) {
    ESP_LOGW(kTag, "activation task already running");
    return;
  }

  // activation task 栈从 PSRAM 分配，避免 internal RAM 碎片化导致创建失败
  StaticTask_t *tcb = static_cast<StaticTask_t *>(
      heap_caps_malloc(sizeof(StaticTask_t), MALLOC_CAP_SPIRAM));
  StackType_t *stack = static_cast<StackType_t *>(
      heap_caps_malloc(kActivationTaskStackBytes, MALLOC_CAP_SPIRAM));
  if (tcb == nullptr || stack == nullptr) {
    ESP_LOGE(kTag, "failed to alloc activation task memory from PSRAM");
    free(tcb);
    free(stack);
    EmitErrorEvent(ESP_FAIL, "failed to create activation task");
    Schedule([this]() { SetDeviceState(DeviceState::kIdle); });
    return;
  }

  activation_task_handle_ = xTaskCreateStatic(
      [](void *arg) {
        auto *self = static_cast<Application *>(arg);
        self->ActivationTask();
        self->activation_task_handle_ = nullptr;
        vTaskDelete(nullptr);
      },
      kActivationTaskName, kActivationTaskStackBytes / sizeof(StackType_t),
      this, 5, stack, tcb);

  if (activation_task_handle_ == nullptr) {
    ESP_LOGE(kTag, "failed to create activation task (static)");
    free(tcb);
    free(stack);
    EmitErrorEvent(ESP_FAIL, "failed to create activation task");
    Schedule([this]() { SetDeviceState(DeviceState::kIdle); });
  }
}
```

### 需要添加的头文件

在文件顶部已有 `<esp_system.h>`，还需确认 `<esp_heap_caps.h>` 是否已包含（`heap_caps_malloc` 需要它）。

### 注意事项

1. **栈释放**：`xTaskCreateStatic` 的栈由调用方管理，`vTaskDelete(nullptr)` 不会释放静态栈。需在 `application.h` 中新增 `StackType_t *activation_task_stack_` 和 `StaticTask_t *activation_task_tcb_` 成员变量，在 `StartActivationTask` 中赋值，在析构函数 `~Application()` 中（等待 activation task 退出后）调用 `free()` 释放。失败路径中也要释放。
2. **更简单的替代方案**：如果项目启用了 `CONFIG_SPIRAM_ALLOW_STACK_EXTERNAL`（menuconfig → Component config → SPIRAM → Allow external memory as stack），可以直接保持 `xTaskCreate`，系统会自动从 PSRAM 分配栈。但该选项影响全局，可能引入额外延迟。
3. **任务名修正**：当前任务名是 `"official_ota"`，但日志标签是 `"official_app"`，与 activation task 功能不匹配。建议改为 `"ota_act"` 或保持不变（不影响功能）。
