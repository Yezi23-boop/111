# IMU 六轴实时数值显示测试页面

## 目标
创建一个测试页面，在屏幕上实时显示 IMU (QMI8658C) 的 6 轴加速度和陀螺仪数值，用于手动翻转手表来确定各轴的物理方向映射。

## 当前 IMU 架构概览

```
i2c_manager (GPIO14/15, 400kHz, 共享总线)
  └─ qmi8658c (0x6B, 芯片驱动)
       └─ imu_sensor (抽象层, imu_sensor_read() → accel.x/y/z + gyro.x/y/z)
            └─ imu_service (50Hz采样, FreeRTOS task, 事件窗口)
```

- `imu_sensor_read(imu_sensor_sample_t*)` 是读取 6 轴数据的核心 API
- 数据结构: `accel.x/y/z` (m/s²), `gyro.x/y/z` (deg/s)
- IMU 已由 `imu_service` 在启动时初始化完成

## 实现方案

### 新增文件
1. **`main/ui/custom/imu_test_view.h`** — 视图头文件
2. **`main/ui/custom/imu_test_view.c`** — 视图实现（独立 screen + 6 个数值标签）

### 修改文件
3. **`main/ui/custom/custom.c`** — 注册测试页面，在 `custom_init()` 中自动打开
4. **`main/ui/lvgl_task.c`** — 主循环中添加 `imu_test_view` 的定时器刷新（或在 view 内部用 lv_timer 自驱动）

### 页面布局

```
┌─────────────────────────────────┐
│        IMU 六轴测试             │  ← 标题 (y=30, 居中)
│                                 │
│  Accel (m/s²)                   │  ← 分类标签
│    X:  -0.23                   │
│    Y:   9.78                   │
│    Z:   0.12                   │
│                                 │

│    Y:  -0.12                   │
│    Z:   0.03                   │
│                                 │
```

安全区: x∈[40,370], y∈[20,480]

### 朝向判断逻辑

根据 board_imu.h 的物理映射，取加速度绝对值最大的轴判断朝向：
| 条件 | 显示 |
|------|------|
| \|accel.z\| 最大且 z < 0 | 正面朝上 (Face Up) |
| \|accel.z\| 最大且 z > 0 | 背面朝上 (Face Down) |
| \|accel.x\| 最大且 x > 0 | 左侧朝上 (Left Up) |
| \|accel.x\| 最大且 x < 0 | 右侧朝上 (Right Up) |
| \|accel.y\| 最大且 y > 0 | 顶部朝上 (Top Up) |
| \|accel.y\| 最大且 y < 0 | 底部朝上 (Bottom Up) |

阈值: 最大轴 > 7.0 m/s² 才显示朝向，否则显示"倾斜/平放"。

### 刷新机制

- 使用 `lv_timer_create()` 创建 100ms (10Hz) 定时器
- 定时器回调中调用 `imu_sensor_read()` 读取最新数据
- 用 `lv_label_set_text_fmt()` 更新各标签
- 数字使用 `lv_font_montserratMedium_27` 字体，朝向标签使用中文字体 `lv_font_montserrat_lxgw_tghz_level1_3500_22_4`

### 入口方式

**开机自动进入**: 修改 UI 初始化流程，在 `lvgl_task.c` 或 `custom.c` 中，首次加载时直接进入 IMU 测试页面而非主表盘。测试完成后改回即可。

## 关键文件路径

| 文件 | 作用 |
|------|------|
| `components/imu_sensor/include/imu_sensor.h` | IMU 读取 API + 数据结构 |
| `components/imu_sensor/imu_sensor.c` | imu_sensor_read() 实现 |
| `main/services/imu_service.c` | IMU 初始化入口 |
| `main/ui/custom/custom.c` | custom_init() 注册入口 |
| `main/ui/lvgl_task.c` | UI 主任务（确认启动顺序） |
| `main/app/app_main.c` | 启动编排（imu_service 在 deferred 阶段启动） |

## 启动时序注意

`imu_service_start()` 在 `start_deferred_services()` 中调用，晚于 `lvgl_task` 创建。
测试页面的定时器回调需要优雅处理 IMU 未就绪的情况：
- `imu_sensor_read()` 返回非 ESP_OK 时，显示 "Waiting for IMU..."
- 首次成功读取后切换到正常数据显示

## 验证步骤

1. `idf.py build` 编译通过（无 error）
2. `idf.py -p <PORT> app-flash` 烧录
3. 开机后自动进入 IMU 测试页面
4. 初始显示 "Waiting for IMU..."，约1-2秒后切换为实时数据
5. 翻转手表至6个面，观察：
   - accel 三轴数值变化（静止时一轴接近 ±9.8，其余接近 0）
   - 朝向标签是否正确显示对应方向
   - gyro 数值（静止时接近 0，转动时有明显变化）
6. 记录各轴对应的实际物理方向，与 board_imu.h 中的映射对比验证
