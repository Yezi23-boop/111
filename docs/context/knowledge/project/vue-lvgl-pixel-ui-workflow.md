# Vue → LVGL → 真机 UI 开发工作流

## 定位

本流程用于把 UI 开发从“直接写 LVGL、肉眼调样式”收敛为可重复的三阶段流水线：

```text
Vue 设计定稿 → LVGL host 模拟器复刻达标 → 构建、烧录、真机验收
```

Vue 是复刻阶段的视觉基准，LVGL host 模拟器是部署前的验证环境，真实手表是最终交付环境。三个阶段必须按顺序推进，不能用模拟器截图代替真机验收。

本文件记录已经固定的目标、边界和验收标准，状态为 `active`。本轮已落地 `AGENTS.md` 门禁、Vue 捕获脚本和截图差异工具；音乐页面完整试点与真机验收仍需按后续任务执行，流程启用不等于业务页面已经验收完成。

## 阶段一：Vue PC 端设计

### 目标

用 Vue 快速设计和定稿页面，不以当前 LVGL 实现反向限制设计。Vue 页面是本轮 UI 复刻的视觉源，不是最终设备运行环境。

### 设计要求

- Vue 页面必须可独立运行，并支持固定测试数据。
- 用户修改 Vue 文件后通过 Vite HMR 立即看到结果。
- Agent 修改 Vue 文件后也通过同一套 HMR 预览结果。
- 不要求用户和 Agent 同时编辑同一个文件；实时预览不等于并发写入。
- 设计稿必须覆盖页面结构、尺寸、间距、颜色、圆角、边框、图标、图片和文字层级。
- 需要定义正常态、按下态、选中态、禁用态、加载态、空态、错误态、弹层和滚动状态。
- 动态文字必须使用可重复的测试数据，不能只依赖网络实时数据。
- 设计完成后生成固定尺寸的基准截图，并由用户确认“设计定稿”。

### 设计冻结

用户确认设计定稿后，Vue 版本和基准截图冻结，进入 LVGL 复刻阶段。复刻过程中不能为了迁就 LVGL 当前代码而悄悄修改 Vue；如果视觉方案确实需要变化，必须重新打开设计阶段并重新确认基准。

## 阶段二：LVGL host 模拟器复刻

### 目标

在 PC 上把 Vue 定稿页面复刻到 LVGL，并通过可重复截图和量化差异确认复刻结果。

### 统一画布

Vue 基准截图、LVGL host 截图和差异工具必须使用相同的：

- 画布尺寸：`410 × 502`；
- 方向和裁剪区域；
- 缩放比例，禁止截图后再缩放；
- 测试数据和页面状态；
- 动画冻结时机；
- PNG 输出格式。

截图必须去除浏览器工具栏、模拟器窗口边框和额外留白。需要等待布局、字体、图片和首帧渲染完成后再捕获。

### 分层复刻顺序

每个层级单独截图、单独对比、单独验收，不只比较最终整页：

1. 屏幕背景、圆角外壳和安全区。
2. 页面主容器、整体布局和滚动容器。
3. 卡片、按钮、边框、分割线和间距。
4. 图片、图标和其他静态素材。
5. 标题、正文、辅助文字和动态文字。
6. 播放、暂停、选中、按下、禁用等控件状态。
7. 滚动位置、弹层、遮罩和其他叠加层。
8. 返回、下拉、长按、滑动和页面切换后的视觉状态。

每一层都必须能说明：基准图、LVGL 图、差异图、差异数值和是否通过。

### 自动迭代闭环

用户确认 Vue 定稿后，Agent 可以在同一层内自主循环，不需要每一轮询问用户：

```text
读取 Vue 基准
  ↓
实现一个 LVGL 层级或状态
  ↓
构建并启动 host 模拟器
  ↓
执行固定操作进入目标状态
  ↓
截图并生成差异图
  ↓
按差异报告定位最大偏差
  ↓
调整 LVGL
  ↓
再次截图对比
```

出现以下情况时暂停并请求用户决定：设计稿本身冲突、缺少素材或字符覆盖、LVGL 能力无法实现设计、动态数据规则未定义，或者无法判断应以设计稿还是硬件行为为准。

## 像素级对比标准

“像素级”必须由固定规则和报告定义，不能只凭肉眼或整页相似度。

### 结构和素材区域

背景、容器、边框、图片、图标和按钮位置属于结构区域：

- 主要坐标误差不超过 `1 px`；
- 容器尺寸误差不超过 `1 px`；
- 图片和图标不得出现明显缩放、裁剪或错位；
- 颜色比较使用固定的通道容差；
- 结构区域差异率不超过初始基线 `0.5%`。

### 文字区域

浏览器和 LVGL 的字体抗锯齿栅格化可能不同，因此文字不强制要求两个渲染器每一个抗锯齿像素完全相同，但必须比较并保持一致：

- 文字区域位置；
- 基线和行高；
- 字号和字重层级；
- 字间距；
- 换行位置；
- 截断、横向滚动或页面滚动策略；
- 长文本下周围布局是否变化。

文字差异容差只能用于渲染器产生的有限抗锯齿差异，不能掩盖整体偏移、字号错误、换行错误、颜色错误或字体缺字。首次试点需要用真实截图校准文字容差，校准后固定，不能每个页面临时放宽。

### 对比产物

每次对比至少输出：

- Vue 基准截图；
- LVGL 截图；
- 差异叠加图或差异热力图；
- 结构区域和文字区域的差异率；
- 最大差异区域及其坐标；
- 当前层级的通过或未通过结果。

## 动态文字、字号和字体资源

UI 设计优先考虑视觉层次和可读性，现有字体资源是优先复用材料，不是设计硬边界。

- 字号按文字角色复用，尽量减少相近字号；现有字号能满足设计时优先复用。
- 现有字号无法满足层次、可读性、语言覆盖或版式时，可以新增字号。
- 字体家族不是 UI 设计的首要限制，可以按页面需要选择或创建；但必须验证字符覆盖、字宽、行高和 LVGL 实际效果。
- 固定静态文案可以按视觉需要创建专用字体、字号和字符子集。
- 来自网络、音乐服务、用户输入或 AI 的开放动态文字，不能使用只按当前页面固定文案生成的页面小子集字体。
- 在不使用字体 fallback（回退链）的前提下，开放动态文字必须使用覆盖目标数据域的字体；发现覆盖缺口时要报告，不得静默替换。
- 动态文字必须位于固定尺寸容器中，并预先确定省略、换行、横向滚动或页面滚动方案。
- 不允许根据运行时字符串长度随意缩小字号或撑开周围布局。
- Vue 中新增的字号应标注后续 LVGL 所需字体资源；不能让 Vue 使用的字号在 LVGL 复刻阶段被无说明地替换。

## 动态数据测试集

音乐、通知和 AI 页面至少使用以下数据验证：

- 短中文；
- 长中文；
- 中英文混合；
- 数字和标点；
- 较长歌名；
- 较长歌手名；
- 多行正文；
- 空数据；
- 加载状态；
- 错误状态；
- 需要滚动的内容。

Vue 测试数据应成为 LVGL host 的固定测试夹具，保证每次截图比较内容一致。动态内容必须在设计阶段确定固定宽度、自适应宽度、单行省略、多行换行、横向滚动和页面滚动中的具体方案。

## 阶段三：构建、部署和真机验收

### 部署门槛

只有满足以下条件才允许进入上板阶段：

1. Vue 设计已由用户确认定稿。
2. LVGL host 已完成所有目标层级和目标状态。
3. 截图对比达到固定阈值。
4. 用户已确认 LVGL 模拟器整页效果和操作流程。
5. 必要的构建验证已经通过。

host 预览通过不等于板端一定正确。上板仍需验证 CO5300 显示、FT5x06 触摸、字体资源、屏幕生命周期、刷新性能、动态内容和真实手感。

### 真机验收

真实手表是最终交付环境，用户需要实际验收：

- 屏幕整体构图和可视安全区；
- 触摸、滑动、长按和返回；
- 页面切换和滚动；
- 动态歌名、歌手名、通知和 AI 正文；
- 字体是否缺字、错位或溢出；
- 图片、图标和颜色；
- 刷新是否卡顿、闪烁或出现异常残影。

真机发现视觉问题时，先判断问题属于 Vue 设计、LVGL 复刻、host 与板端差异还是硬件显示链路，不能直接用肉眼结果覆盖前面的对比证据。

## 用户介入点

用户不参与每一轮细小参数调整，只在关键门禁介入：

1. Vue 设计定稿。
2. 每个复刻层级达到自动标准后的视觉确认。
3. LVGL host 整页和交互验收。
4. 真机最终验收。

Agent 在门禁之间自主完成截图、对比、定位、修改和再次验证。

## 首个试点

先用音乐页面验证完整流程：

```text
Vue 音乐页定稿
→ 固定状态截图
→ LVGL 音乐页复刻
→ host 模拟器截图
→ 分层差异图和数值报告
→ 用户确认
→ 构建、烧录
→ 用户在手表上验收
```

音乐页面作为首个业务试点，后续补充页面专用的分层配置、状态夹具和经实测校准的文字差异阈值。通用截图命令、差异工具和流程门禁已经固定；业务页通过后再记录实际的 host 与真机差异。

## 当前不包含的内容

- 不在本文件中定义具体页面的最终视觉方案。
- 不把当前 Vue 页面自动视为已经定稿的设计稿。
- 不承诺浏览器和 LVGL 的文字抗锯齿像素天然完全一致。
- 不用 host 截图替代真实手表验收。
- 不在流程试点前新增复杂的通用 UI 编辑器或大型对比平台。
