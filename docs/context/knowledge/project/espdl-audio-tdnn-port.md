# ESP-DL 音频 TDNN 移植结论

外部训练仓库位于 `D:\esp32S3\AudioClassification-Pytorch`。首版推荐链路为 `TDNN + Fbank + TAP`，固定 16 kHz mono、3 秒整窗，训练侧输入 `[1,298,40]`。

ESP-PPQ 1.2.10 可解析并导出 `.espdl`，但原始 TDNN 的 `Conv1d + BatchNorm1d` 图在量化时存在通道维转换风险。当前导出脚本 `tools/espdl/export_tdnn_for_espdl.py` 默认将模型等价改写为 ESP-DL 友好的 2D 图，导出输入为 NCHW `[1,1,298,40]`，板端 ESP-DL 运行时按 NHWC 暴露为 `[1,298,40,1]`，并已用 UrbanSound8K 的真实 Fbank `.npy` 特征做 32 步校准。

部署样板位于 `D:\esp32S3\AudioClassification-Pytorch\deploy\esp32s3_audio_cls`，通过 IDF component manager 拉取官方 `espressif/esp-dl`。样板 `sdkconfig.defaults` 已按 `D:\esp32S3\111` 主工程的 ESP32-S3 板级基线对齐到 CPU 240MHz、32MB flash、Octal PSRAM 80MHz、8MB factory app 分区，并保留 `assets/model/audio` 数据分区；默认关闭 Fbank dump 的正常固件已重新烧录，app 大约 `0x118620` 字节。

当前 `.espdl` 文件本体为 197,776 字节，作为 `FLASH_RODATA` 嵌入，主要占 flash/rodata，不应直接等同于 RAM。2026-04-30 真机 monitor 实测 `model_->get_memory_info()`：`total internal=5,892 B`、`total psram=263,112 B`、`total flash=197,760 B`；其中 `variable psram=87,184 B`、`parameter_copy psram=171,584 B`、`others internal=5,892 B / psram=4,344 B`。后续讨论板端 RAM 以这段日志为首版基线。

训练/导出阶段无法得到 ESP-DL allocator 的精确 RAM，但 `tools/espdl/export_tdnn_for_espdl.py` 已增加 `local_resource_estimate`：从 `.espdl` 文件大小和 `.info` 的 value/initializer tensor 形状估算 flash、输入特征缓存、最大 activation、两缓冲 activation 与朴素全 tensor 上限。首版默认只记录估算值，不设置硬门禁；试更大模型时再启用 `--max_espdl_file_kb`、`--max_two_buffer_ram_kb`、`--max_naive_tensor_ram_kb`。

Fbank 对齐工具已补齐：`tools/espdl/dump_reference_fbank.py` 可生成训练侧 `[298,40]` 参考 Fbank，并解析板端串口 `FBANK,...` CSV dump 计算 `max_abs_error`、`mean_abs_error` 和最大误差位置。样板工程默认生成同款 `0x12345678` 种子的 LCG 宽带伪随机参考 PCM，`kEnableFbankDump` 默认关闭；2026-04-30 真机对齐实测 `max_abs_error=4.72e-05`、`mean_abs_error=1.70e-06`，属于浮点实现误差级。全量 `FBANK,...` CSV 会在 `printf` 控制台路径长时间阻塞，诊断 dump 期间会临时把 Task WDT idle 监控 mask 设为 0，并在 dump 后恢复默认配置；常规固件 monitor 已确认 `FBANK_ROWS=0`、无 WDT。

2026-04-30 使用真实样本 `C:\Users\ye\Desktop\stdio\esp32_siren\1-31482-A-42.wav` 做端到端冒烟测试。训练侧脚本对该样本输出 `children_playing(2)`、confidence `0.879821`；板端样板将同一音频按训练侧归一化后嵌入为 `test_audio/real_sample_pcm_float32.bin`，真机输出 `children_playing(2)`、confidence `0.6401`，同时无 WDT。该样本文件名像 siren，但当前模型没有识别成 `siren`，只能证明真实音频链路和 PC/板端 top1 一致，不能作为危险声精度达标证据。

2026-05-01 继续做 4 条真实样本批量测试时发现量化校准顺序问题：`dataset/features` 按类别子目录排序，而旧导出命令 `calib_steps=32` 只会取类别 0 的前 32 条。`tools/espdl/export_tdnn_for_espdl.py` 已改为按父目录轮询交错校准特征，并用 `calib_steps=320` 重导出 `.espdl`。重导出后板端结果：外部 `sample_00_esc_siren` 仍为 `children_playing(2), 0.5265`；UrbanSound8K `sample_01_us8k_car_horn` 为 `gun_shot(6), 0.9840`；`sample_02_us8k_gun_shot` 为 `gun_shot(6), 0.7758`；`sample_03_us8k_siren` 为 `siren(8), 0.9998`。说明量化校准漂移已明显改善，但当前训练模型本身仍混淆部分 car_horn/gun_shot。

2026-05-01 按“排除 gun_shot，测试准确率 0.90+”做 9 类训练实验。新增 `dataset/*_no_gunshot.txt` 与 `dataset/label_list_no_gunshot.txt`，过滤原始类别 6，并将原类别 7/8/9 重映射为 6/7/8。首个 128-channel TDNN best accuracy 为 `0.8726`；256-channel 实验 best 为 `0.8833`；最终 `configs/espdl/training/tdnn/tdnn_espdl_urbansound8k_no_gunshot_acc90_gpu.yml` 使用 `channels=512`、`embd_dim=192`、`dropout=0.25`、`label_smoothing=0.08`、`AdamW`、`batch_size=256`，GPU 训练 best epoch 76，测试准确率 `0.9241`。对应导出目录为 `models/training_runs/espdl_export/tdnn_urbansound8k_no_gunshot_acc90_gpu_20260501`，`.espdl` 文件约 `2,349,648` 字节，本地估算 two-buffer activation 约 `301,056` 字节、initializer 约 `2,323,436` 字节。该模型精度达标但显著大于首版 128-channel 模型，接入前必须板端实测 `get_memory_info()` 和推理耗时。

2026-05-01 继续训练 `configs/espdl/training/tdnn/tdnn_espdl_urbansound8k_no_gunshot_256_reg.yml`，保持 `channels=256`、`embd_dim=128`，加入 `dropout=0.25`、`label_smoothing=0.08` 和 `AdamW`，GPU 训练 best epoch 55，测试准确率 `0.9185`。对应导出目录为 `models/training_runs/espdl_export/tdnn_urbansound8k_no_gunshot_256_reg_20260501`，`.espdl` 文件 `647,744` 字节；本地估算 two-buffer activation 约 `150,528` 字节、initializer 约 `621,484` 字节。真机烧录实测 `get_memory_info()`：`total internal=5,892 B`、`total psram=788,296 B`、`total flash=647,728 B`，其中 `variable psram=162,448 B`、`parameter_copy psram=621,504 B`。4 条嵌入真实音频批测中，Fbank 约 `85-90 ms`，单次 ESP-DL 推理约 `2,860 ms`；UrbanSound8K siren 样本输出 `siren(7), 0.9346`，外部 siren-like 样本和 car_horn 样本仍输出 `dog_bark`。该模型比 512 版本更适合继续做首版工程验证，但 2.86 秒离线整窗推理仍不满足实时危险识别。

当前可用版本已冻结为 `edge_danger_tdnn192_fbank1s_int8_v20260502`。版本清单位于 `configs/espdl/model_versions/edge_danger_tdnn192_fbank1s_int8_v20260502.json`，说明文档位于 `docs/espdl/model_versions/edge_danger_tdnn192_fbank1s_int8_v20260502.md`。active `.espdl` 与 versioned snapshot 的 SHA256 均为 `1B6E503DF47C16DAD80F64D8E7E35B31D1F7D6E9F43A40DE557977BDA3446501`。后续更大 RAM 模型、UrbanSound8K 混训模型或阈值实验必须新增 version_id，不得覆盖该 locked baseline。
